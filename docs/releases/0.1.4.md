# v0.1.4

发布日期：2026-11-10。

新增操作记录、官方出水历史同步和 P30 奶瓶添加向导。

## 操作与出水历史

- 具有对应数据点的恒温壶、泡奶机增加本地出水和烧水记录；消毒柜增加消烘记录，双舱分别计数。
- 记录以设备回读为依据，保存于 HA 私有 Store，重启后保留；每类实体展示最近 50 条及累计次数。
- 烧水和消烘的暂停、恢复算同一次；退出运行不等于正常完成。断线、重启和切换通道不会补造离线记录。
- 新增独立的“官方出水历史”实体，分页回填可查询到的全部记录，支持重启续传。
  私有缓存保存全部同步条目，实体展示最近 50 条。
- 完整回填后约每 5 分钟核对最近一天的修改和删除。同步失败保留上次完整结果，不阻塞 LAN 状态读取和控制。
  仅 LAN 模式读取已有缓存，不查询云端。

## P30 奶瓶添加

在“设置 → 设备与服务 → BOLOLO → 配置”中勾选“添加奶瓶”，选择在线 P30、已在官方 App
创建的宝宝和奶瓶名称。按向导清空托盘、放置空奶瓶并确认称重，待设备返回有效编号后确认保存。

清盘、称重和云端保存均需显式操作。命令失败或保存结果不明时不自动重发，应先到设备或 App 核对。
中途退出请使用向导内的“取消并重置”。保存需要云端连接；设备自动解童锁偏好保持原值。

## 升级

通过 HACS 更新并重启 Home Assistant。手动安装请用 `bololo-0.1.4.zip` 整体替换
`custom_components/bololo/` 后重启。`bololo-smart-control.zip` 为 HACS 布局，手动使用时解压到组件目录。
已有账号配置无需删除；首次读取设备状态时建立本地记录基线。

## 验证与边界

210 项自动化测试通过，Ruff 检查和格式检查通过。测试覆盖本地记录、双舱、断线与重启、
云端分页回填与增量核对、缓存持久化、LAN 隔离、卸载取消，以及奶瓶向导的异常结果和禁止重放。

官方出水历史与奶瓶接口来自官方 P30 模板的静态核对，尚未真机验证；其他 Wi-Fi 型号的云端历史
兼容性仍待确认，缺少云端 `sno` 的设备无法查询。30 秒轮询可能漏掉短操作或相同水量上报。
烧水与消烘尚无可核实的官方历史接口，不能同步接入前的 App 历史。更早出水记录的修改不在最近一天核对范围内。

协议来源和限制见 [分析记录](../../analysis/HISTORY.md)，操作细节见 [README](../../README.md)。

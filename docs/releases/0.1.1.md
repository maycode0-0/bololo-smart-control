# v0.1.1

本版为 BOLOLO 波咯咯接入增加 LAN 优先的混合传输，安装包为 `bololo-0.1.1.zip`。

## 变化

- 默认优先通过局域网读取和控制，必要时按安全边界回退云端；另提供仅云端和仅 LAN。
- 本地实现 UDP 发现、设备身份匹配、TCP 认证和数据点通信，按次建立短连接。
- 可自动从设备取得 LAN passcode，也可按设备指定 IPv4 和 passcode。
- 将最小设备库存保存在 Home Assistant 私有 Store 中；已有缓存后，默认模式和
  仅 LAN 模式可在不先登录云端的情况下重启。首次添加账号仍需云端登录和清单。
- 为实体增加配置模式、最近成功通道和云端状态上报时间属性，并在诊断中提供
  不包含账号秘密和设备地址的传输结果。
- README 按通道策略、安装、配置、支持范围、故障定位和开发文档组织，补充设备
  支持说明与文档索引。
- 增加 MIT 许可证、HACS 元数据和 GitHub Actions；测试、HACS/hassfest 校验通过后自动发版。
- 安装包区分 HACS 根目录布局与完整路径手动布局，可重复构建并校验内容，已发布资产不覆盖。

## 回退边界

本地读取失败可以回退云端读取。控制只有在确定物理命令尚未发送时才允许云端回退。
已经写出、但响应超时或结果无法确认的动作不会跨通道重发，以免重复执行。

仅 LAN 模式不调用云端，也不更新云端设备清单。设备新增或解绑后，需要先通过
可访问云端的模式同步库存。

## 验证范围

基础 HA 加载、实体注册、控制服务和卸载使用真实 Home Assistant 2024.12.5 API
离线验证。LAN 协议依据来自原始 APK 的静态逆向；自动化测试与真实设备执行分别
记录，不把模拟服务器或离线测试结果当作硬件验证。

128 项自动化测试通过，Ruff 检查和格式检查通过。协议测试覆盖固定字节向量和
真实回环 UDP/TCP 模拟设备；传输测试包含卸载期间禁止新建云端回退请求。

Z60/P30 尚未完成真实设备与实际网络测试。仍需确认具体固件的 LAN 服务、设备发现、
本地认证、指令执行和长期运行稳定性。P30 仍没有日常远程出水功能，BLE 吸奶器仍不在
接入范围。

## 安装与升级

将安装包解压到 Home Assistant 配置目录，确认组件位于
`<ha-config>/custom_components/bololo/` 后重启。已有安装应整体替换组件目录，
避免残留旧文件；无需为同一账号重新创建集成。

完整步骤与网络要求见 [README](../../README.md)，型号与字段限制见
[设备支持范围](../DEVICE_SUPPORT.md)。

# v0.1.7

发布日期：2026-11-25。

修正官方出水历史查询的请求体格式，使其与 App“泡奶周报 → 所有记录”的调用链一致。

## 修复

此前使用了另一条官方服务调用的 AEP 外层封装。重新追踪 P30 模板的“所有记录”调用链后，
确认它通过模块 3746、1271 和 1161，向相同的 `type=3` 路径直接发送分页 JSON。
本版历史查询改为直接发送 `{current,size,query:{startTime,endTime}}`，保留认证头和响应校验。
重新认证后的查询也使用相同请求格式，其他接口保持原有封装。

首次查询在第一页失败、尚未接受任何分页时，后续重试将截止时间推进到当前时间，避免遗漏失败后产生的记录。
已有分页进度时仍使用固定查询窗口，重启后继续读取剩余页，避免分页边界变化导致漏读。

## 升级

通过 HACS 更新并重启 Home Assistant。手动安装请将 `bololo-0.1.7.zip` 解压到 HA 配置目录，
整体替换 `custom_components/bololo/` 后重启。`bololo-smart-control.zip` 为 HACS 布局。
已有账号、历史缓存和回填进度保留，无需删除集成。

用水总量仍需官方历史与水量字段完整后才显示数字。升级后可查看 `sync_status`、`sync_error`、
`staged_count` 和缓存日期范围，确认回填进展。仅 LAN 模式不会访问云端，需切换自动或仅云端模式同步。

## 验证与范围

275 项自动化测试、Ruff 检查和格式检查通过。回归覆盖直接 JSON 请求、重新认证后保持请求格式、
首页失败后重启重试更新截止时间，以及已有分页进度继续使用固定窗口。

本次修复来自静态调用链核对及离线自动化测试，尚未用真实账号验证云端结果。
服务器历史保留期和实际查询限制仍待确认。协议来源更正见 [分析记录](../../analysis/HISTORY.md)。

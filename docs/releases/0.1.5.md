# v0.1.5

发布日期：2026-11-24。

修复用水总量累计、消烘记录漏记和整数数值显示，并明确 Z60 保管参数的时间单位。

## 修复内容

- “用水总量”由显示单次出水量改为累计已确认水量，单位为 mL。本地累计保存于 HA 私有 Store，
  重复轮询、重启和最近 50 条明细裁剪不会重复计入或清零。
- 官方出水历史完整回填后，“出水记录”和“用水总量”使用全部官方缓存的条数与水量之和，
  不再叠加本地观察结果。重复同步不会增加总量，已同步窗口中的修改和删除会修正总量。
- 消烘状态与模式分开上报时保留已观察到的启动时间；模式字段缺失或为 0 时，
  可由设备回读的唯一活动自动、烘干或杀菌开关识别运行。暂停和恢复仍计为同一次。
- 整数状态、错误和故障值显示为整数，实际带小数的测量值保留小数。
- Z60 的保管时间与自定义保管时间显示分钟，温暖保管时长显示小时；这些参数是设定时长。
- 记录实体增加 `cloud_sync_supported` 属性，明确当前是否实现对应云端同步。

## 升级与数据范围

通过 HACS 更新并重启 Home Assistant。手动安装请将 `bololo-0.1.5.zip` 解压到 HA 配置目录，
整体替换 `custom_components/bololo/` 后重启。`bololo-smart-control.zip` 为 HACS 布局，
手动使用时解压到组件目录。已有账号配置无需删除。

旧版没有保存本地累计水量，升级时只能从仍保留的最近明细恢复；更早已裁剪的水量无法在本地还原，
可通过官方出水历史完整回填补齐可查询范围。完整官方缓存存在后，即使切到仅 LAN 模式，
出水记录和用水总量也继续显示该缓存，直至恢复云端同步。本地观察独立保存，不混入官方结果。
`record_source` 和 `last_synced` 可用于核对来源及同步时间。

官方历史允许校正和删除，累计水量可能随同步向下修正，传感器使用 `total` 状态类别。
官方历史仍按约 5 分钟核对最近一天，更早记录的修改和删除不会自动核对。

## 验证与限制

265 项自动化测试通过，Ruff 检查和格式检查通过。新增回归覆盖累计持久化、明细裁剪、旧数据迁移、
延迟水量、官方缓存优先与去重、消烘分开上报、模式开关识别、整数解码及真实 HA 实体状态。

本次验证为离线自动化验证，未进行 Z60/P30 真机联调。30 秒轮询仍可能漏掉短操作或相同水量上报。
官方出水接口来自 P30 模板，其他机型兼容性仍待确认。烧水与消烘的 App 历史接口仍未核实，
目前仅记录 HA 观察到的变化，不能同步接入前的 App 历史。

# v0.1.2

新增短信验证码登录，适合只有验证码登录入口的 BOLOLO 账号。继续默认 LAN 优先、按发送状态安全回退云端。

## 变化

- 首次添加默认通过短信验证码登录；选择注册国家/地区、填写拨号区号与裸手机号后提交发码。
- 当前 App 路径先取得 codeToken，再调用 V2 发码；登录使用带 `+` 与拨号区号的完整手机号及 ISO 地区码。
- 提供显式重发、60 秒冷却、服务端频率限制提示及人工图形验证码步骤。
- 验证码只用于当次认证，不保存；登录会话存入 HA 私有配置和认证 Store，自动续期并在重启后复用。
- 续期令牌在使用前持久化；写入失败时中止该请求，旧运行实例不能回写覆盖新会话。
- 会话失效走 HA 重新认证，须登录同一账号，不自动发送短信。旧密码配置可继续使用。
- 保持已有库存下的 LAN 离线启动；云端认证失效且 LAN 可用时保留本地操作并提示重新认证。

## 安装与升级

通过 HACS 升级并重启 HA，或将 `bololo-0.1.2.zip` 解压到 HA 配置目录，整体替换
`custom_components/bololo/` 后重启。HACS 布局安装包为 `bololo-smart-control.zip`。
已有集成无需删除；没有成功添加过账号的用户重新添加并选择短信验证码即可。

验证码会话被服务器撤销时，在 HA 的重新认证提示中输入原账号并获取新验证码。
HA 配置与备份包含登录会话，请妥善保管。诊断导出不包含验证码和认证令牌。

## 验证范围

使用 Home Assistant 2024.12.5 API 及离线模拟验证短信请求、验证码错误与重发、图形验证码分支、
会话恢复与续期、持久化失败、账号隔离、重新认证、LAN 优先和控制不重放。

160 项自动化测试、Ruff 检查和格式检查通过，HACS 与手动安装包已完成构建校验。

短信接口依据 Android App 2.1.86 的静态分析恢复，见 [分析记录](../../analysis/SMS_LOGIN.md)。
尚未使用真实账号发送短信或验证图形验证码实际显示及在线登录，Z60/P30 的具体固件 LAN 能力仍待实机确认。
本版没有增加 P30 日常远程出水或 BLE 吸奶器支持。
